# Product redesign: before / after

Baseline: frontend checkpoint `b03a3af`. The working tree was clean when the
founder's redesign began. Existing live API integrations were retained.

| Before | After |
| --- | --- |
| Seven equal sidebar tools | Four primary destinations; advanced tools disclosed separately |
| Database overview as application home | Dashboard compatibility redirect to Discover |
| Large source counts and coverage tables at entry | A search-led next action with project cards |
| Country/source/year/sector/label/sort form | Country/topic first; More filters drawer |
| Dense project table on desktop | Cards with title, source excerpt, evidence and shortlist action |
| Long raw descriptions and evidence panels | Project story; full descriptions and evidence expandable |
| Multiple raw funding lines, including repayments | Up to three funding-flow facts initially; all details retained |
| Model/version/benchmark information competing with input | Description and useful result first; technical details on demand |
| Manual source-ID entry to seed comparison | Build a shortlist directly through discovery and detail |
| Automatic comparison and broader database prioritization | Explicit comparison and prioritization of saved projects only |
| Repayment groups alongside primary funding comparison | Further financial/non-funding observations in a disclosure |
| Budget planner as a primary product tool | Contextual hypothetical simulation from the shortlist |
| Repeated technical access text | One compact notice with complete source/access detail available |

The marketing landing page and its live source/model previews are intentionally
unchanged because the founder approved that page. No wallet balances, fictional
transactions, returns, funding offers or synthetic project scores were introduced.

The earlier local screenshots remain under ignored `artifacts/frontend/`
(filenames such as `390-_analytics.png` and `1440-_dashboard.png`). Redesign
captures use the `redesign-` prefix, including Discover, detail, analysis,
shortlist comparison, light/dark and responsive views. These artifacts contain
source data and are not committed or published. Current QA is documented in
[redesign_visual_qa.md](redesign_visual_qa.md).
