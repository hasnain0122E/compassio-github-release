# Data quality audit

Full machine-readable register: `artifacts/data_audit/data_quality_issues.csv`, generated by
`uv run compassio-data audit`. It has one row per issue, with severity, category, field,
affected-record count, description and recommendation. This document summarises the register and
adds context. Counts are observed on the registered files; `source_inventory.md` lists the hashes.

Severity: **critical** = blocks or distorts the intended use unless handled; **warning** = must be
handled in cleaning or display; **info** = document and carry forward.

## Critical

| Source | Issue | Records | Handling |
| --- | --- | ---: | --- |
| aiddata / research_paper | **Retrospective descriptions.** AidData's definition covers implementation, achievements and shortcomings. 8,699 research descriptions mention a year later than their commitment year. | 20,985 | No point-in-time claims. Chronological evaluation = year-shift test. |
| research_paper | **Duplicate descriptions.** 1,351 rows share a normalized description (514 groups); 15 groups (49 rows) have conflicting labels. | 1,351 | Grouped splits. Report the conflicting groups as label noise. |

No label is missing or malformed: all 20,985 `rio_marker` values parse, so the
`research_rio_marker_missing_or_invalid` check found nothing. No AidData amount lacks its currency,
no ADB transaction lacks a currency, and no ADB transaction type is unknown. These checks exist and
are tested, but found nothing in the real files.

## Additional observations (not in the register)

- Research titles are truncated to 255 characters in 12 rows, and one research description dropped
  the word "null" (`cross_source_overlap.md` §2).
- AidData `Actual Implementation Start Date` begins in 1996, before the 2000 commitment window. It
  records pre-commitment implementation proxies. That is AidData's convention, not an error.
- ADB transaction history before 2013-12-31 is absent for disbursements and repayments, although
  commitments start in 2005. Cumulative disbursement per instrument cannot be reconstructed from
  this file.
- CPE: 380 documents have no `Document Type`, and 12 document rows share a content URL.
