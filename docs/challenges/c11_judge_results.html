Limits

An IP limiter cannot distinguish devices behind NAT or defeat a distributed botnet. Global screening ceilings can throttle legitimate screening under identity churn. Read capacity is separate. This fixture experiment does not establish canonical-model or unlimited-load capacity. Baseline already throttles. Raw timing receipts are local in artifacts/c11; compact metrics accompany this page. No external assets, scripts, network calls or chart libraries are required.
